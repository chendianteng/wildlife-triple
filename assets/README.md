# Artwork

- `game-icon.png`: the user's supplied image, copied unchanged. Used in the game header, browser favicon, Apple touch icon, and link preview.
- `wildlife-atlas.png`: one illustrated sprite atlas generated with the built-in `image_gen` tool. Explicit source rectangles in `index.html` display each character without clipping adjacent artwork.

## Generation prompt

Use case: stylized-concept. Asset type: one production game sprite atlas, 4 columns by 3 rows, a single combined PNG texture for a matching game. The supplied image is a STYLE REFERENCE only: match its irresistibly cute softly shaded painted toy-like animals, round shapes, shiny kind eyes, rosy cheeks, cheerful faces, warm cream highlights. Create exactly twelve isolated illustrations laid out on an exact regular 4-column 3-row grid covering the whole rectangular canvas. Suggested size 1536x1152 (4:3). Each invisible equal-sized cell contains ONE large centered illustration, fully inside its own cell, with at least 10% clear padding on each edge. Row 1, left to right: happy panda face, blue butterfly with open wings, golden yellow snail, toucan head with orange beak. Row 2 left to right: cute bright green lizard, smiling orange fox face, happy tan monkey face, friendly brown bear face. Row 3 left to right: pink five-petal flower, single emerald monstera leaf, small round-canopy green tree, baby elephant face with short trunk and big lavender-gray ears. No words, no letters, no labels, no outlines of grid cells, no tile slabs, no card frames, no scenery, no extra creatures. These should look like the ANIMALS ON THE TILES in the reference, not a recreation of the whole poster. Strong unique silhouettes, large expressive faces, clean edges and colors readable at 60px. Truly transparent background throughout all empty space; no opaque rectangle, no checkerboard baked into artwork. All twelve illustrations consistent lighting, texture, scale and style. Centers precisely at x=12.5%,37.5%,62.5%,87.5% and y=16.6667%,50%,83.3333% of the canvas.

The first output painted a checkerboard rather than transparency. It was discarded. The green character was rendered as a frog, so the game labels it as a frog.

No checkerboard anywhere. Preserve all twelve character illustrations, positions, centers, scale, shapes, coloring, and 4-column 3-row geometry exactly. OPAQUE FLAT IVORY backdrop, no transparency requested, no background shadows or gradients. No grid lines, no text, no tiles, no additional objects.
